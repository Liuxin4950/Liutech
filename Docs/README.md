## 文档分工

| 目录 | 维护内容 |
| --- | --- |
| `架构/` | 当前模块边界、调用链、接口契约与操作约束；每个模块以 `总览.md` 为入口 |
| `SQL/` | 唯一完整初始化快照、不可改写的已发布迁移及旧结构测试夹具 |
| `教程/` | 教学与事故排查案例；当前实现链接回模块架构 |
| `归档/` | 写作时的评估、需求和方案；其中的版本、行号与性能估算是历史证据 |

总体模块关系只在架构总览维护，统一编码规则只在跨服务规范维护，生产版本只在部署运维维护，数据库迁移版本只在迁移说明维护。其它文档引用这些入口。

## 维护

改动功能时同步对应模块；接口变更同步接口参考，数据库变更同步快照、增量、结构检查与 MySQL 回归，发布后更新生产版本和验证依据。具体规则见 [Docs/AGENTS.md](AGENTS.md)。

从仓库根目录运行 `node scripts/check-docs.mjs`，检查文档路径、章节锚点、模块索引和当前架构文档长度。CI/CD 当前状态见[维护清单](维护清单.md)。

旧的[当前架构入口](记录/当前架构.md)、服务目录下的[AI 接口入口](../LiuTech-AI/AI接口文档.md)与[根部署指南](../快速部署指南.md)仅保留跳转，正文统一维护在上表对应位置。
