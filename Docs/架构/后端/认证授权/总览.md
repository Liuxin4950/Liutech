# 认证授权架构总览

> 前后端一体的登录与访问控制：后端 JWT + 统一授权白名单，前端登录弹窗体系与 401 统一拦截。读完能定位"谁在拦、怎么放行、未登录怎么办"的完整链路。

## 模块职责

**后端**（`LiuTech/`）：JWT 无状态认证 + 路径白名单。`SecurityWhitelist.java` 定义公开访问范围，由 `SecurityConfig` 配置授权规则。`JwtAuthenticationFilter` 独立识别任意请求中携带的有效 token，使公开文章接口也能取得当前用户的点赞、收藏和购买状态；没有 token 的游客仍可访问公开接口。

**前端**（`Web/`）：登录入口统一为全局登录弹窗（不跳页），表单逻辑单点定义，HTTP 401 统一在 axios 拦截器处理。登录成功停留当前页，不打断阅读。

## 数据流概览

### 后端白名单判定（一次请求）

```
请求进入
  │
  ├─ JwtAuthenticationFilter: 提取 Authorization Bearer token
  │     ├─ 无 token → 不建立身份
  │     ├─ 有效 token + 当前用户可用 → 注入 SecurityContext
  │     └─ 无效 token / 用户禁用或删除 → 不建立身份
  │
  └─ SecurityConfig 授权：白名单 permitAll / /admin/** hasRole('ADMIN') / 其余 authenticated
```

**关键顺序**：`AUTHENTICATED_PATHS` 在 `SecurityConfig` 中先于 GET 公开前缀配置，保证公开前缀下的登录接口仍需认证。公开访问权限不影响有效 token 的解析；认证失败时，公开接口继续按游客处理，受保护接口返回 401。

### 前端登录链路

```
触发点（任选其一）
  ├─ TheHeader「登录/注册」按钮 → authModalStore.show()
  ├─ 路由守卫 requiresAuth 未登录  → show(提示, to.fullPath) + next(false)
  ├─ api.ts 拦截器 401（会话失效）→ 清 token + show('登录状态已失效')
  ├─ 点赞/收藏/购买/下载未登录     → show(具体提示)
  └─ BottomNavigation 发布文章/我的文章 → show(具体提示)
        │
        ▼
LoginModal（全局唯一实例，MainLayout 挂载）
  ├─ useAuthForm 提交：密码登录 / 邮箱验证码登录 / 注册
  │    └─ 失败：字段级红字（校验）/ toast（业务错误，弹窗保持可重试）
  └─ 成功 → 关弹窗 + 清 redirect
        ├─ 有 redirect（守卫拦截）→ router.push 跳回目标页
        └─ 无 redirect → 停留当前页；PostDetail watch isLoggedIn 自动刷新点赞收藏状态
```

## 陷阱与约束

- **授权白名单只决定访问权限**：公开接口仍识别有效 token，不能在 JWT 过滤器中按公开路径提前返回。
- **公开前缀下的需登录接口必须加 AUTHENTICATED_PATHS**：`/posts/` GET 前缀是公开的，新增 `/posts/` 下的登录接口（如 `/posts/my`、`/posts/favorites`、`/posts/view-history`）必须同步列入，否则游客也能被授权访问
- **拦截器内不能顶层实例化 store**：`router/index.ts` / `api.ts` 在模块加载期执行，pinia 尚未安装；`useAuthModalStore()` 必须在守卫回调 / 拦截器回调内调用
- **401 排除 `/user/` 接口**：登录/注册/验证码接口的 401 属于业务失败（防御性），走业务提示而非"会话失效"弹窗（`api.ts:105-112`）
- **守卫拦截用 `next(false)` + 弹窗**：不跳登录页，登录成功后经 redirect 跳回被拦截页；`next(false)` 取消导航，当前页不丢失
- **弹窗关闭必须清理**：`resetForm()` 统一清理验证码倒计时 timer（防泄漏）与表单残留（防下次打开带旧输入）；组件卸载同样调用 `cleanupTimers`
- **跨服务身份边界**：见 [跨服务规范](../../跨服务规范.md) 第 5 节；AI 通过主服务身份内省获取身份。
