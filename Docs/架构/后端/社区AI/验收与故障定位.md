# 社区 AI 验收与故障定位

> 从预演到正式参与，每一步都使用网站事实、任务状态和发布回执判断结果。

## 升级与首次启用

1. 按既有数据库备份约定备份两库，在已有环境依次执行[主库增量迁移](../../../SQL/migration_community_backend.sql)与[AI 库增量迁移](../../../SQL/migration_community_ai.sql)。迁移支持重放；不要使用完整初始化脚本覆盖已有环境。
2. 构建并启动两个服务及前后台；启动命令与环境约定见[CLAUDE.md](../../../../CLAUDE.md)。社区默认关闭，不会为已有文章补评。
3. 后台“社区 AI”创建两个角色，分别填写身份、性格、自定义提示词和兴趣，添加各自文本资料。
4. 在“预演与邀请”选择角色、输入公开文章 ID；检查决策、引用资料、读取范围、正文和运行状态。预演不发布评论。
5. 启用角色和全局互动，对一篇文章手动邀请，核对任务、成功运行和前台 AI 作者。
6. 再发布新文章，使用正常回复体验互动；在 Admin“评论与对话”审查实际发言和线程，需要调整时先暂停，再修改角色配置。

新环境使用[唯一完整初始化脚本](../../../SQL/sql.sql)，无需另外执行迁移。部署和真实模型行为验收由当前环境的配置决定；局部数据库或模拟供应商通过不代表真实模型人设质量已经验收。

## 固定验收场景

| 场景 | 操作 | 预期与判断证据 |
| --- | --- | --- |
| 预演隔离 | 全局关闭时预演 | 有 PREVIEW、模型用量和决策，评论数量不变，记忆不新增 |
| 角色资料隔离 | 两角色分别放不同资料，再预演 | 工具只允许当前角色资料 ID，运行记录显示来源 |
| 正常沉默 | 不相关话题或模型明确 SKIP | 任务 SKIPPED，不创建空评论、不误报发布成功 |
| 首次发布 | 创建并发布新文章，再编辑、重复发布或撤回重发 | 首次最多两个候选；之后不新增同一首次发布事件 |
| 直接互动 | 在 Web 正常回复 AI 评论 | 该评论作者进入任务，模型仍可沉默，前台无角色邀请面板 |
| 后台审查 | 查看角色评论并打开所在对话 | 同时展示真人、其他 AI 及软删记录；历史运行保留当次提示词快照 |
| 互聊上限 | 两角色连续发言 | 同 rootEventId 的实际发布数不超过 maxChainComments |
| 暂停 | 推理期间关闭角色、全局或文章 | 主后端拒绝旧结果，不新增评论 |
| 内容改变 | 推理期间修改正文或相关评论 | 旧 contextVersion 不能发布；有限重试重新准备上下文 |
| 浏览统计 | 多次预演和内部读取文章 | viewCount 不变；公开读者浏览仍按既有逻辑统计 |
| 重复投递 | 同事件重新领取、重启 AI 服务 | eventId/botId 不重复建任务；同 taskId 不重复发表 |
| 应答丢失 | 正式发布后以相同 taskId 重交 | 返回原 commentId；评论、链计数和额度只增加一次 |
| 清空记忆 | 生成期间清空角色记忆，再等待完成 | 旧 memoryEpoch 不能重新写回旧摘要 |
| 来源失效 | 删除或撤回来源内容后查看记忆 | 相关摘要不再进入展示或模型上下文 |
| 前台轮询 | 展开回复、输入内容，等待刷新；切到隐藏页 | 同 ID 对象保留，输入状态不丢失，隐藏页停止轮询 |

## 运行记录的阅读顺序

```text
文章 / 评论是否仍公开
 → 角色、文章、全局开关是否允许
 → 业务事件是否已经产生且 availableAt 到期
 → 对应任务是否存在，租约和重试状态是什么
 → 是否获得本日模型尝试额度
 → 实际读取了哪些资料和范围，工具是否截断或失败
 → 模型返回 SKIP / COMMENT / REPLY 中哪一个
 → 是否仍使用当前 contextVersion
 → 是否有 SUCCEEDED 与 publishedCommentId
 → 前台刷新是否取得该评论
```

`PREVIEW` 和 `GENERATED` 不代表发表。模型文字中声称发布或读完全文也不是执行证据，应核对读取范围、工具交付与主后端回执。

## 故障定位

| 现象 | 核对 |
| --- | --- |
| 回复之后没有回应 | 被回复评论作者、enabled、事件、延迟、任务、SKIP 理由和额度 |
| 两个角色不再互聊 | 根链计数、冷却、兴趣候选、角色决策与今日额度 |
| 任务一直 READY | AI 服务是否运行、内部接口是否可用、全局 worker 租约是否未到期 |
| 有 GENERATED，没有评论 | 提交错误、暂停、contextVersion 变化、链/日额度，或网络重试 |
| 评论已存在但任务没成功 | 主后端发布回执；保持同一 taskId 重交，不删除任务后重新生成 |
| 旧文章没有自动评论 | 迁移已标首次已见，使用手动邀请 |
| 清理后记忆仍出现 | 角色 ID、memoryEpoch、来源可见性和是否为清理后的新互动 |

业务错误码与实际 HTTP 日志用于定位故障；界面只显示用户可读原因。不要在生产开启整包 DEBUG 来打印模型提示词或凭据。
