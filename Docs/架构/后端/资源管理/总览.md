# 资源管理架构总览

> 资源（zip/pdf/音频等）的上传、购买鉴权下载、管理端维护与下载记录。读完本文能看懂一个资源从「上传」到「被积分用户下载」再到「被彻底删除」的完整链路，以及下载鉴权与积分扣减的安全设计。

## 模块职责

资源 = 可下载的文件或外部链接，分**免费**与**积分**（付费）两种下载类型。涉及：

- 上传：文件走存储层（本地磁盘/COS，与图片共用 `FileStorage` 抽象），外部链接直接存 URL
- 购买：积分资源先购买（扣积分）再下载，唯一索引防重复购买
- 下载：后端鉴权后经存储层流式返回（不直出 URL，防止绕过积分）
- 管理：管理端 CRUD、软删/恢复/物理删除、下载记录查询

前端位置：Web 端在文章详情页下载附件（[`Web/src/views/PostDetail.vue:245`](../../../../Web/src/views/PostDetail.vue)），Admin 端在资源管理页（[`Admin/src/views/admin/ResourcesManagement.vue`](../../../../Admin/src/views/admin/ResourcesManagement.vue)）。

## 数据流概览

```
上传（管理端/文章编辑器）
  FileUploadController /upload/resource
    → FileUploadService.uploadResource
      → fileStorage.save（本地或 COS，路径 resources/...）
      → resources 表插入（downloadType/pointsNeeded）
      → （可选）post_attachments 草稿附件关联

购买（积分资源）
  ResourceDownloadController POST /resource/purchase/{id}
    → purchaseResource：先插 download_logs（唯一索引防重）
    → PointsService.deductPoints（原子扣减，SOURCE_RESOURCE_DOWNLOAD）
    → 任一失败事务回滚

下载
  ResourceDownloadController GET /resource/download/{id}
    → 鉴权：免费 / 已购买 / 上传者本人，否则拒绝
    → extractResourceRelativePath（统一走 FileUtil 口径 + resources/ 前缀 + 穿越校验）
    → fileStorage.open 读取 → 流式返回（不直出 URL）

管理端
  ResourcesAdminController /admin/resources/*
    → 列表 / 创建 / 更新 / 软删 / 恢复 / 物理删（删物理文件 + 下载记录 + DB 记录）/ 下载记录分页
```

## 陷阱与约束

- **URL 解析必须走 `FileUtil.extractRelativePath` 统一口径**：曾自实现只认 `/uploads/` 前缀，COS 直出 URL（`https://static.liuxin.chat/resources/...`）解析失败导致下载报「非法资源路径」——已收敛到 FileUtil（兼容相对路径/站内完整 URL/COS 直出），新写解析不要自己拼。
- **物理删除必须删物理文件**：曾只删 DB 记录和下载记录，COS/本地文件残留成孤儿——`permanentDeleteResource` 已补 `fileUtil.deleteFileByUrl`（单条与批量都覆盖，外部链接资源 fileUrl 为空自动跳过）。
- **下载鉴权在服务端**：文件流经后端代理返回，不暴露 COS/本地直出 URL，防止绕过积分系统直接访问。
- **路径安全**：`isInvalidRelativePath` 拦截绝对路径与 `..` 目录穿越（[`ResourceDownloadService.java:229`](../../../../LiuTech/src/main/java/chat/liuxin/liutech/service/ResourceDownloadService.java)），对本地磁盘与 COS 统一生效。
- **防重复购买**：`download_logs` 表 `uk_user_resource` 唯一索引 + `DuplicateKeyException` 捕获（[`sql/sql.sql`](../../../../sql/sql.sql)）。
- **扣积分顺序**：先插购买记录、后扣积分，扣减失败靠事务回滚，避免"积分扣了但购买记录没插上"。
- **免费判定**：`isPaidResource` = `downloadType != FREE` **或** `pointsNeeded > 0`，两个条件任一成立都算付费，需购买后才能下载。
- **上传者免购买**：资源上传者本人下载不扣积分（`hasUserPurchased` 判断）。
- 积分流水与余额扣减由 PointsService 统一管理，资源模块只传 `SOURCE_RESOURCE_DOWNLOAD`（`resource_download`）来源标识。
