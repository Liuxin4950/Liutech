# 数据库初始化与基础配置

> 新环境统一执行 [Docs/SQL/sql.sql](../../../SQL/sql.sql)。该文件同时包含两库的完整结构和可公开的基础数据；已有环境按[数据库版本迁移](../../../SQL/migrations/README.md)升级，不重放完整脚本。

## 结构与数据范围

当前完整快照包含主库 33 张表、AI 库 14 张表，结构与 2026-10-07 的合并版本一致，公开基础数据来自 2026-10-06 云端 `53965f5`。用户生命周期状态表保留结构；备份表与 Flyway 历史记录不进入新库。

| 数据 | 初始化行为 |
| --- | --- |
| 分类、标签、文章系列 | 云端当前未删除的名称与描述，按名称去重，不沿用生产 ID |
| 作者与关于页 | 云端公开的 `author.*`、`about.content`，已有值保留 |
| 欢迎公告 | 播种当前常驻公开公告，浏览数从零开始，同标题已存在则不重复插入 |
| 模型目录 | 新目录以 DeepSeek-V3.2 为唯一启用的默认模型；Qwen2.5-7B 初始停用，可在后台启用 |
| 语音配置 | SiliconFlow、CosyVoice2、MP3、44100 Hz；初始关闭，自定义音色 URI 与密钥按环境配置 |
| 社区互动 | `community_settings(id=1)` 默认关闭，`ai_community_worker(id=1)` 提供租约入口 |
| 账号、文章、评论、会话、任务、发布回执与记忆 | 不复制生产数据，不创建固定密码管理员，不预置虚构互动 |

云端当前没有轮播记录；Web 使用已有默认横幅。上传文件、音乐和账户专属音色不随 SQL 复制，不能只复制数据库路径而省略对应文件。

## 默认模型的唯一来源

运行默认模型来自 `ai_model_config`；管理台「模型配置」调用 [AiModelConfigService.setDefaultModel](../../../../LiuTech-AI/src/main/java/chat/liuxin/ai/service/AiModelConfigService.java) 在事务中清除旧默认并设置新默认，随后失效缓存。聊天、写作和评论角色共用 [AiModelPolicy](../../../../LiuTech-AI/src/main/java/chat/liuxin/ai/infra/security/AiModelPolicy.java)。只修改 YAML 不会替换数据库中的默认选择。

新模型目录的初始化基准：`deepseek-ai/DeepSeek-V3.2`，上下文窗口 `164000`、输出上限 `32768`、温度 `0.4`，与本次核对的云端配置一致；这是站点配置快照，不是供应商限额承诺。输入预算和实际消耗见 [模型预算与安全](../../后端/AI服务/模型预算与安全.md)。

模型种子只补缺失项，只有模型表为空才初始化默认选择。重复执行不会重置管理员的启用状态、默认模型、参数、作者资料或互动开关。若已有目录没有默认模型，应在管理台明确选择，不能靠重放初始化强行修复。

## 新环境启动顺序

1. 按 [.env.example](../../../../.env.example) 配置两库密码、内部令牌、JWT 与模型 API Key；跨服务边界见 [跨服务规范](../../跨服务规范.md)。密钥不写入 SQL。
2. 空库执行唯一完整 SQL；Docker MySQL 的初始化目录仅在数据卷首次创建时执行。应用数据库账号通过 [mysql/init-users.sh](../../../../mysql/init-users.sh) 从环境变量创建并分别授权 CRUD。
3. 启动主后端和 AI 服务。通过正常注册创建真实账户，再按[首次管理员步骤](部署操作.md#首次管理员)显式提权，不复制生产登录账号或密码哈希。
4. 在「模型配置」核对默认 DeepSeek-V3.2；通过 `/ai/runtime` 确认实际默认，不用付费生成测试来代替配置核验。
5. 如需语音，在「语音服务」填好本账户音色并启用。评论角色在「评论角色」配置与预演后开启，流程见 [社区 AI](../../后端/社区AI/总览.md)。

## 已有环境与验证

已有环境先备份两库，按当前完整 SQL 核对结构差异，使用 `scripts/migrate.ps1` 升级两库至 V3 并 validate。迁移版本与执行顺序以[数据库版本迁移](../../../SQL/migrations/README.md)为准。完整脚本的 `CREATE TABLE IF NOT EXISTS` 不会为旧表补列。初始化种子保留已存在的数据，不应作为在线配置同步器使用。

主库 V2、AI 库 V3 为旧环境补齐社区表、评论作者约束、执行任务与公共记忆；已部署评论区 AI 的环境只补缺失结构并登记台账，不重置角色和互动配置。主库 V3 补齐验证码查找索引，保留既有过期清理索引。启动结构检查覆盖生命周期与社区关键字段，避免缺迁移时带病运行。

验证使用临时空库：完整创建 47 张表、核对字段、检查中文与 emoji、唯一默认、社区租约及默认暂停；修改默认模型、作者名、语音和互动配置后再次执行，确认定制值保留且基础数据不重复。临时库验证结束后移除，开发库和生产库不重置。
