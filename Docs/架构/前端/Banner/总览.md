# Banner 架构总览

> 全局常驻 Banner 系统：双形态（hero / subheader）、无状态 store 定制、页面级路由重置。读完能定位到各页面的 Banner 定制入口与展示层逻辑。

## 模块职责

Banner 是 `MainLayout` 中常驻的全局横幅组件，承担两类职责：

1. **hero（500px 大横幅）**：首页及一级页的默认轮播展示（接口轮播图，无数据时默认欢迎语）
2. **subheader（280px 页眉）**：详情/列表页的页面标题展示（文章标题 + 分类徽标）

设计为「无状态 store + 页面上传配置」：store 只做原子赋值与清空，不做隐式默认与推断；每个页面进入时自行 `setBanner` 上传完整配置，未定制的页面由 `MainLayout` 统一 `resetBanner` 回默认轮播。前端在 `Web/`，无后端依赖（轮播数据走 `carousels` 接口，见 `Web/src/services/carousel.ts`）。

## 数据流概览

```
路由切换
  │
  ├─ 进入定制页（/post/、/category-detail/、/tags、/series、/categories、/archive、/about、
  │     /my-posts、/view-history、/favorites）
  │    页面自身 setBanner(完整配置)   ← MainLayout 不干预
  │
  └─ 进入非定制页
        MainLayout 路由 watch（CUSTOM_BANNER_PATHS 不匹配）→ resetBanner()
              │
              ▼
      Banner.vue slides computed（133 行）数据优先级：
        config.slides（页面定制） > carousels（接口轮播，getActiveCarousels）
        > [fallbackSlide]（默认欢迎语，仅 hero 模式）
        subheader 且 config.slides 空 → 返回 []（无图渐变页眉，不显示 LiuTech 默认内容）
```

渲染细节（Banner.vue）：

- 徽标文字 `badgeText`（108-111 行）：定制态用 `config.badgeText`，否则 `Welcome`
- 标题高亮 `bannerTitleHighlight`（114-119 行）：定制态用 `config.titleHighlight`；仅纯默认态（无定制且无接口轮播数据）追加 `LiuTech`；接口轮播图用自身标题不追加
- 配色：默认欢迎语（`is-fallback`，120-124 行）`LiuTech` 蓝色（`--color-primary`）+ 副标题橙色（`--color-secondary`）；无图模式（`is-dark`）标题橙色高亮延续页面标题组合语言
- hero 模式图片带 Ken Burns 缓慢放大动画；无图时渐变底 + 径向光斑（`banner-decor`）

## 陷阱与约束

- **不在页面卸载时 resetBanner**：路由切换时旧页面 `onUnmounted` 的 reset 可能晚于新页面 `setBanner` 执行，产生竞态；统一由 `MainLayout` 路由 watch 在**进入**时决定（`MainLayout.vue:39` 注释）
- **`setBanner` 必须传全字段**：`BannerConfig` 全字段必填（TypeScript 编译期强制），缺失字段漏编译错；store 无默认值兜底
- **subheader 空态返回空数组**：页面数据未到时（如 PostDetail 加载中）slides 为空，Banner 只显示渐变页眉，不显示 LiuTech 默认欢迎语（`Banner.vue:133-136`）
- **文章加载失败需 resetBanner**：PostDetail 在 onMounted 无条件设了 subheader 空态，若文章不存在（草稿/已删），`loadPostDetail` 的 onError 必须 `resetBanner()` 恢复默认轮播，否则残留空渐变页眉
- **bannerTitleHighlight 不污染接口轮播**：接口轮播图有数据时（config 未定制），slides 取 carousels，此时不追加 `LiuTech` 高亮（`Banner.vue:115-118`）
- **封面长图适配 banner**：详情页 banner 用文章封面（长图），列表缩略图优先用 thumbnail（正常尺寸），二者用途不同不要互换（见 `ArticleList.vue` thumbnail 优先取值）
- **数据优先级次序**（定制 > 接口轮播 > 默认欢迎语）在 `slides` computed 一处定义，改动只改这一处
- **用户中心页用 hero + banner0 品牌图**：MyPosts/Favorites/ViewHistory 三页标题由 banner 承载（无页面内 .page-title 区块），`setBanner` 的 titleHighlight 与 tab 状态联动（MyPosts 我的文章 ↔ 草稿箱）；新增用户中心页记得同时加入 `CUSTOM_BANNER_PATHS` 并在 MainLayout 挂载处确认
