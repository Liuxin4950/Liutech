# 阅读与发现架构总览

> 前台文章列表、搜索、系列导航、公开站点资料及页面 SEO 的入口。

## 模块职责

页面负责分类/标签资料和 Banner；公共列表 composable 负责分页、排序与请求代次。搜索、本文目录、系列清单分别拥有内部样式。公开 SEO 使用现有 `@vueuse/head`，不直接维护多份 `document.title`。

## 数据流概览

```text
排序 / 翻页 → router.query(sort, page) → usePostListing
  → PostService（popular 转为 hot）→ PostsController → PostsService
  → postList 缓存键包含 sort → PostsMapper 按白名单排序并分页

搜索弹窗打开 → tag store 热门标签 + 本地最多 8 条历史
  → 输入防抖 / Enter → 文章搜索 → 只提交最新请求结果
  → 点击真实标签 → /tags/{id}

文章详情 → 本文目录 + seriesCatalog
  → 宽屏同面板上下排列；1680px 以下折叠且可切换本文/系列
  → 正文底部只保留系列进度与上下篇
```

## SEO 与资源加载

`App` 调用 `usePageSeo`，文章 `useHead` 覆盖标题、纯文本摘要、Article JSON-LD 和分享信息。文章 canonical 使用稳定数字 ID，与 sitemap 一致；历史带 slug 地址仍由路由解析，但不再在 Vue Router 之外修改浏览器 URL。

列表标题提供真实链接，普通点击沿用页面跳转，修饰键点击保留浏览器行为。正文图片异步解码、延迟加载，列表封面使用既有 thumbnail；Banner 只给当前图片高加载优先级。Live2d/AiChat 由 MainLayout 按需加载。

首页在窄屏下让侧栏排在文章列表之后，并为异步列表预留至少一屏高度，避免请求返回前侧栏先进入首屏、文章卡片插入后再被整体推出视口造成布局偏移。

[Web/nginx.conf](../../../../Web/nginx.conf) 对 `/assets/` 构建产物长期缓存，对同名公开资源短缓存并重新验证，HTML 入口 `no-cache`。实际 CDN 规则和部署边界见[部署运维](../../运维/部署运维/总览.md)。客户端 head 更新不能证明所有抓取器能获取正文；线上抓取/预渲染结论以 PRD 验收记录为准。

## 陷阱与约束

- 排序必须进入 SQL 和缓存键，仅改变 select 或当前页数组不会改变全量排序。
- 页面切换、清空输入、关闭弹窗和组件销毁必须使旧请求失效。
- 搜索热门标签按公开文章数据提供，不代表搜索次数；损坏的本地历史会被过滤。
- 目录和系列共享高度预算，不能在高度为 0 的悬浮宿主内无限伸长；内部样式由子组件持有。
- 备案资料来自 `VITE_ICP_NUMBER`、`VITE_POLICE_NUMBER`、`VITE_POLICE_CODE`，未配置则不显示，不填写假编号。
