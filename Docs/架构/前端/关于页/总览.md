# 关于页架构总览

> 关于页模块负责作者资料、个人介绍、技术栈、项目经历、荣誉与联系信息的统一存储、管理和前台展示。

## 模块职责

关于页的业务内容不再写死在 Web 组件中。作者基础资料继续复用 `system_settings` 中的 `author.*`，其他页面内容作为 JSON 存入 `about.content`。Admin 通过强类型接口编辑，Web 通过公开接口读取；CSS 类名、间距、颜色、动画和图标 key 不进入数据库。

## 数据流概览

```text
Web /about
  -> GET /about
  -> AboutPageService.getAboutPage()
  -> author.* + about.content
  -> JSON 解析与必填结构完整性校验
  -> AboutPageResp
  -> Web 渲染页面并更新 Banner/SEO

Admin /关于页管理
  -> GET /admin/about
  -> 结构化表单编辑（技能与技术关键词均为自由文本）
  -> PUT /admin/about
  -> AboutPageReq 参数校验
  -> author.* 与 about.content 在一个事务内更新
  -> 清除 aboutPage 缓存

Web 技术栈 / 项目关键词
  -> skillGroups[].skills / projects[].technologies
  -> 统一渲染为 #关键词
  -> 不读取文章 tags / post_tags

Web 社交链接
  -> socialLinks[].href
  -> Web 根据 mailto / GitHub 域名 / 普通链接选择展示图标
```

## 存储边界

| 配置 | 内容 |
| --- | --- |
| `author.name` | 作者名称，同时供首页和 AI 作者资料链路使用 |
| `author.title` | 作者头衔 |
| `author.avatar` | 作者头像 URL |
| `author.bio` | 首页作者简介 |
| `about.content` | 座右铭、介绍段落、社交链接、技术栈、项目、荣誉、联系文案、Banner 和 SEO 描述；关于页内容唯一事实源 |

`about.content` 是单例页面配置，不提供按项目查询、多语言版本或历史版本能力。

其中三个容易混淆的结构边界固定为：

- `skillGroups[].skills` 是有序字符串数组，Web 统一使用 `#` 前缀展示，不存每项图标。
- `projects[].technologies` 是项目技术关键词，只用于关于页展示；它不是博客标签，不含 `tagId`，不参与文章搜索、筛选或聚合。
- `socialLinks[]` 只保存 `label`、`value`、`href`；Web 从链接推导邮件、GitHub 或普通网站图标，避免重复类型字段与链接不一致。

## 缓存与异常状态

- `aboutPage` 是 `CacheConfig` 声明的 10 分钟 Caffeine 读缓存；Admin 发布时全量失效。
- `about.content` 缺失、无法解析或必填结构不完整时，后端记录错误并明确返回配置错误；不会用 Java 硬编码内容掩盖生产数据问题。
- Web 不再保留一份完整写死内容；请求期间显示加载态，失败时显示重试。
- 荣誉图片未配置时，Web 使用编译内置的默认插画。

## 陷阱与约束

- 不要把 CSS class、尺寸、颜色、动画、布局开关或 Web 图标 key 存入 `about.content`。
- Java 代码不保留关于页业务文案副本；真实初始化内容和结构迁移由 `sql/sql.sql` 与迁移 SQL 管理。
- Admin 只通过强类型 `/admin/about` 发布，不直接编辑 JSON。
- About 的技术关键词与博客 `tags` / `post_tags` 永久分离，不调用 `TagsService`。
- 技能与项目技术关键词统一渲染为 `#关键词`；社交图标只在 Web 根据链接推导。
- 头像、荣誉图片与项目链接仅支持站内路径或 HTTP(S)；社交链接额外支持 `mailto`。
- 当前契约不兼容旧 `icon` / `tags` JSON；部署前需直接把既有 `about.content` 迁移为无图标字段、`skills: string[]` / `technologies` 的结构。
- `/user/author/profile` 继续保持原有语义，首页与 LiuTech-AI 无需迁移到关于页接口。
- 部署到既有数据库前需执行本模块迁移 SQL。跨服务与数据库硬约束见 [`AGENTS.md`](../../../../AGENTS.md) 和 [`Docs/记录/当前架构.md`](../../../记录/当前架构.md)。
