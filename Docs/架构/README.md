## 阅读建议

- **改后端代码前**：先读 [跨服务规范.md](跨服务规范.md)，对照其第 8 节检查清单，确保复用统一实现、不造新轮子
- **接手某模块**：先读对应模块目录的「总览.md」，再按需跳转细分文档
- **跨模块问题**：先查 [Docs/记录/当前架构.md](../记录/当前架构.md)，再回到本目录找具体模块
- **新增功能**：在对应模块目录下补文档，更新本 README 的模块导航表

## 文档约定

- 每个模块一个目录，以「总览.md」为入口
- 单一领域文档不超过 500 行
- 代码引用用 `file:line` 格式，可点击跳转
- 数据流用文字流程图，不依赖外部图片
- 标注「陷阱/约束」小节，记录已踩过的坑
