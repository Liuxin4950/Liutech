## 1. 问题 / 需求概述

对项目前后端进行全站代码质量与安全审计，发现并修复以下问题：

- 前端暗色模式残留硬编码颜色
- 前端代码质量问题（响应式 bug、死代码、DOM 泄漏、调试日志）
- 后端安全问题（CORS 通配符、缺失输入校验、邮箱暴露）
- 后端代码质量问题（调试输出、静默异常）

## 2. 实现内容

### 2.1 前端暗色模式修复

| 文件 | 修改 |
| --- | --- |
| `CommentForm.vue` | 提交按钮 `#000` → `var(--color-primary)`，暗色模式不再不可见 |
| `TheHeader.vue` | 主题切换图标内联样式 `#333333` → `var(--text-main)` |
| `Login.vue` | 2 处 `rgba(45,144,205,...)` → `rgba(var(--color-primary-rgb),...)` |
| `CreatePost.vue` | 2 处 `rgba(45,144,205,...)` → `rgba(var(--color-primary-rgb),...)` |
| `AnnouncementCard.vue` | 徽章颜色 `#dc2626`/`#2563eb`/`#ea580c`/`#6b7280` → CSS 变量 |

### 2.2 前端代码质量

| 文件 | 修改 |
| --- | --- |
| `Archive.vue` | `ref(new Set())` 响应式失效 → `ref<Record<string, boolean>>({})`，修复月份展开不更新 |
| `Favorites.vue` | 移除未使用导入（formatDate、Pagination）和死函数（goToCategory、goToTag、clearSearch） |
| `PostDetail.vue` | Prism.js 注入添加去重守卫和 `onUnmounted` 清理，防止 DOM 累积 |
| `globalErrorHandler.ts` | 移除生产环境 `console.log` |
| `Live2d.vue` | 移除生产环境 `console.log` |
