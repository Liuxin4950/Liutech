## 1. 问题 / 需求概述

- 暗色模式切换后页面不变色，多处组件的 `.dark` 选择器在 scoped 样式下失效。
- About 页面大量硬编码颜色，暗色模式无法适配。
- 导航栏缺少激活项的滑动胶囊动画。
- 仓库中存在无用资源文件和超大二进制文件。

## 2. 实现内容

### 2.1 暗色模式核心修复

**根因：** Vue 3 scoped 样式中 `.dark .xxx` 编译后变为 `.dark .xxx[data-v-xxx]`，而 `.dark` 在 `<html>` 上不带 scoped 属性，导致选择器永远匹配不到。修复方式：统一改为 `:root.dark`。

- `PostDetail.vue`：6 个 `.dark` → `:root.dark` 选择器修复
- `TinyMCEEditor.vue`：22 个 `.dark` → `:root.dark` 选择器修复
- `MainLayout.vue`：删除 5 个几乎不可见的 radial-gradient 装饰渐变（透明度 0.05-0.1），背景简化为纯 `linear-gradient` + CSS 变量

### 2.2 About 页面颜色变量替换

将 About.vue 中所有硬编码颜色替换为 CSS 变量，共涉及 20+ 处：

- `#e8eef7` → `var(--border-base)`
- `#334155` → `var(--text-main)`
- `#64748b` → `var(--text-subtle)`
- `#475569` → `var(--text-subtle)`
- `#f1f5f9` → `var(--bg-hover)`
- `#f8fafc` → `var(--bg-hover)`
- 统计色块背景改用 `var(--bg-info)` / `var(--bg-success)` / `var(--bg-warning)`
- 阴影改用 `var(--shadow-sm)` / `var(--shadow-md)`
- SVG `id="gradient"` → `id="about-name-gradient"` 避免全局冲突
- "留言"联系方式从无 href 的 `<a>` 改为 `<span>` 修复语义

### 2.3 导航栏胶囊滑动动画

- 在 `<ul>` 内添加 `.nav-slider` 滑块元素
- JS 计算激活项位置：`left: -paddingLeft`，`translateX(offsetLeft)`，`width: scrollWidth - paddingRight`
- 动画使用 `cubic-bezier(0.4, 0, 0.2, 1)`，0.4s 时长
- 药丸 `overflow: hidden` 裁切滑块圆角，边缘完美贴合
- 移除原 `::after` 下划线指示器
- 路由切换通过 `watch` + `nextTick` 自动更新

### 2.4 Hero 区域文字颜色

- "刘鑫" SVG：亮色模式白色，暗色模式深色（`:root.dark` 覆盖）
- bio / motto：同上，使用 `rgba` 透明度区分层次

### 2.5 Banner 默认图

- `liuyin.jpeg` → `liuyin.png`，删除 jpeg 文件
