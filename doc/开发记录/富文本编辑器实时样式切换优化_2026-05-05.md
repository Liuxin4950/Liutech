## 1. 问题 / 需求概述

- 背景：Web 和 Admin 共用 TinyMCE 富文本编辑器，主题和样式配置在初始化时写入。
- 用户目标：编辑器样式切换应实时生效，工具栏样式选择也要更直观可用。
- 本次要解决的问题：主题切换时 iframe 内容样式不实时更新；样式预设定义了但工具栏入口不明显；TinyMCE 7 控件命名需要优化；工具栏字体下拉暴露长系统字体栈；quick insert 气泡与输入光标存在视觉偏移；暗色主题下占位提示文字、创建页头部、下拉框和发布前预览样式需要进一步收口；TinyMCE 外壳皮肤在明暗主题切换后残留深色工具栏和状态栏。
- 本次不解决的内容：不调整文章保存接口，不重做富文本渲染样式体系。

## 2. 原因定位

- 现象：切换主题或样式时，编辑器内部内容区不能稳定实时切换样式。
- 根因 / 缺口：TinyMCE 的 `content_style`、`skin`、`content_css` 是初始化配置，初始化后不会自动重新应用到 iframe；原 watch 通过销毁 editor 尝试重建，但 Vue 组件没有显式重挂载，且会带来光标/状态丢失风险。另一个缺口是工具栏仍使用旧式 `formatselect/fontselect/fontsizeselect`，没有把 `style_formats` 暴露为清晰入口。iframe 内部内容样式只设置了 `padding`，未显式清理浏览器默认 `body margin`，会影响空编辑器中的光标和 quick insert 气泡定位观感；系统字体栈也未配置成 TinyMCE 字体格式项，导致工具栏直接显示一长串 `-apple-system...`。另外 `@tinymce/tinymce-vue` 的 `init` 回调签名可能是 `(event, editor)`，旧处理把事件对象当 editor 存储，导致实时主题样式没有真正写入 iframe。外层工具栏和状态栏如果初始化为 `oxide-dark`，切回浅色主题后仍会保留深色 skin 的样式，因此需要固定使用 `oxide`，再由项目 CSS 明确控制明暗两套外壳颜色。
- 证据：`Web/src/components/TinyMCEEditor.vue` 和 `Admin/src/components/TinyMCEEditor.vue` 中主题变化 watch 调用 `editor.remove()`，但模板没有 `key` 或 `v-if` 触发 Editor 组件重建。
- 涉及模块：Web 富文本编辑器、Admin 富文本编辑器。

## 5. 实现内容

### 5.1 后端

- 无后端变更。

### 5.2 前端

- 富文本编辑器外层根据主题添加 `dark` class，让工具栏覆盖样式随主题响应。
- 新增 `applyEditorTheme(editor, mode)`，在 TinyMCE 初始化和主题变化时向编辑器 iframe 写入 `liutech-live-theme` 样式节点。
- 去掉主题切换时销毁 editor 的逻辑，避免内容、选区、光标和初始化状态丢失。
- 工具栏第一组改为 `styles fontfamily fontsize lineheight`，让标题、样式预设、字体、字号和行高都能直接切换，同时避免两个“段落”下拉并排出现。
- 增加 `font_family_formats` 和 `font_size_formats`，同时保留旧的 `font_formats` 和 `fontsize_formats` 兼容。
- 增加“系统默认”字体别名，并限制 TinyMCE 下拉按钮的最大宽度，避免工具栏显示整段系统字体栈。
- 关闭 TinyMCE 默认 `content_css`，由项目注入的 iframe 样式作为唯一主题来源。
- iframe 内容 `html` / `body` 显式设置背景、`margin: 0`、`box-sizing: border-box` 和 `caret-color`，减少空编辑器 quick insert 气泡与输入光标的视觉偏移，并避免正文区域底部露白。
- iframe 内容区补齐 TinyMCE placeholder 伪元素的左右偏移、颜色和透明度，避免暗色模式下默认提示贴边且不可读。
- 兼容 TinyMCE Vue 初始化事件的 `(event, editor)` 与直接 editor 两种形态，保证主题切换 watch 能拿到真正的 editor 实例。
- TinyMCE 外层固定使用 `oxide` skin，避免 `oxide-dark` 初始化后在主题切换时残留深色工具栏和状态栏。
- 对 TinyMCE toolbar、button、split button、select、edit area、statusbar 和 wordcount 显式声明浅色/暗色背景、文字和边框，外壳颜色不再依赖 TinyMCE skin 的初始化状态。
- 写作助手组件按钮、textarea、标题、placeholder 接入主题变量，避免暗色模式下只外层变暗而表单控件仍是浅色默认样式。
- Web 创建页头部从大块卡片改为轻量标题状态，降低暗色模式下的突兀感。
- Web 创建页分类、标签和发布状态下拉框增加主题色、选项色、暗色 `color-scheme` 和统一箭头，减少系统原生控件在暗色模式下的割裂感。
- Web 文章预览继续使用和详情页一致的 DOMPurify 富文本处理规则，并补齐代码块、表格和暗色代码块的样式，降低发布前后视觉差异。

## 6. 安全与性能处理

- 安全影响：无新增 HTML 信任边界；只是编辑器 iframe 内部样式更新。
- 性能影响：主题切换只更新一个 iframe 内 style 节点，避免销毁重建 TinyMCE，性能更稳定。
- 已采取措施：不改文章内容，不触发表单保存，不改变 DOMPurify 消毒边界。
- 遗留风险：未做浏览器手动截图验证，仍建议在开发页切换明暗主题观察工具栏和正文背景。

## 8. 问题记录

| 问题 | 原因 | 处理方式 | 状态 |
| --- | --- | --- | --- |

| 字体下拉过长 | body 系统字体栈未映射到 TinyMCE 字体项 | 增加“系统默认”字体格式并限制 select 标签宽度 | 已解决 |
