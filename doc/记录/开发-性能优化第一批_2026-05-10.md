## 1. 问题 / 需求概述

全站性能审计发现以下瓶颈：
- 文章列表查询 N+1 标签查询（每页 11 次 DB 往返）
- highlight.js 全量导入（~800KB）
- 首屏外图片无懒加载
- 文章列表无缓存
- 64 个纯读方法缺少 `@Transactional(readOnly = true)`

## 2. 实现内容

### 2.1 标签查询 N+1 修复

**问题：** `PostListReslMap` 使用 `<collection select="selectTagInfosByPostId"/>` 嵌套查询，每篇文章触发一次独立标签查询。10 篇文章 = 11 次 DB 往返。

**修复：**
- 从 `PostListReslMap` 移除嵌套查询
- 新增 `selectTagsByPostIds` 批量查询方法（一次 IN 查询拿到所有标签）
- PostsService 新增 `fillTags()` 辅助方法，批量加载后按 postId 分配合并
- 更新 5 个调用点：`getPostList`、`getHotPosts`、`getLatestPosts`、`getPostListForAdmin`、`getFavoritePosts`

**效果：** 10 篇文章从 11 次查询降为 2 次（1 次文章 + 1 次标签）。

### 2.2 highlight.js 选择性导入

**问题：** `import hljs from 'highlight.js'` 导入全部 190+ 种语言（~800KB）。

**修复：** 改为 `import hljs from 'highlight.js/lib/core'`，只注册 10 种常用语言（javascript、typescript、java、python、css、sql、bash、json、xml、markdown）。

**效果：** 从 ~800KB 降到 ~50KB。涉及 `useMarkdown.ts` 和 `MarkdownRenderer.vue`。

### 2.3 图片懒加载

**问题：** 40+ 张首屏外图片无 `loading="lazy"`，首屏加载时全部请求。

**修复：** 为 ArticleList、HotPosts、Drafts、MyPosts 中的文章缩略图添加 `loading="lazy"`。首屏 Banner 图不加。

### 2.4 文章列表缓存

**问题：** `getPostList()` 是最高频查询，每次请求都打 DB。

**修复：**
- CacheConfig 新增 `postList` 缓存区域
- `getPostList` 添加 `@Cacheable`，key 包含所有查询参数
- 10 个写操作的 `@CacheEvict` 新增 `postList`

### 2.5 只读事务标记

**问题：** 64 个纯读方法缺少 `@Transactional(readOnly = true)`，JDBC 驱动无法跳过脏检查。

**修复：** 为 10 个 Service 中的 64 个纯读方法添加 `@Transactional(readOnly = true)`。跳过了含 `view_count` 递增的 `getPostDetail` 和 `getAnnouncementById`。

## 4. 架构影响判断

**无架构影响。** 所有变更为性能优化，不改变业务逻辑、接口协议或数据结构。标签加载从 MyBatis 嵌套查询改为 Java 侧批量查询，结果完全一致。缓存使用 Spring `@Cacheable` + `@CacheEvict` 保证一致性。
