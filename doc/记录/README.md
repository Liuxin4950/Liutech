# 记录目录

本目录存放开发记录与项目架构文档，按"类型前缀 - 功能名_YYYY-MM-DD.md"命名。

```text
doc/记录/开发-功能名_YYYY-MM-DD.md     # 实际改了什么、为什么、怎么验证
doc/记录/架构-功能名_YYYY-MM-DD.md     # 单次架构变化
doc/记录/当前架构.md                    # 长期有效的总体架构，定期汇总
```

`delivery-workflow` 负责产出本目录的文档。

## 何时需要本目录文档

- **开发记录**：所有交付（PRD 实施、小修、Bug 修复）都必须写。
- **架构文档**：有架构影响的功能必须写；无架构影响时在开发记录中说明"无架构影响"即可。
- **当前架构.md**：本次变化改变长期稳定的模块边界、数据流、接口协议或部署拓扑时，必须同步更新。
