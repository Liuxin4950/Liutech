## 1. 问题 / 需求概述

- 背景：用户在生产文章详情页发现“文章目录”占用了文章卡片的显示区域。
- 用户目标：文章内容应保持主要阅读宽度，目录应悬浮在文章卡片左侧；页面宽度不足时目录折叠悬浮，不再挤压正文；目录列表样式更自然，点击目录项时平滑滚动到对应标题。
- 本次要解决的问题：修复 `PostDetail` 文章详情页目录和正文的布局关系。
- 本次不解决的内容：不调整文章内容渲染、目录提取规则、后端接口和生产部署流程。

## 2. 原因定位

- 现象：`post-reading-layout` 使用两列 grid，左列为 `article-toc-panel`，右列为文章卡片，导致目录成为主布局的一列，压缩正文宽度。
- 根因 / 缺口：目录组件的定位从全局 fixed 被父页面改为 static 后，外层 aside 又参与 grid 排版，目录不再是悬浮辅助面板。
- 证据：`Web/src/views/PostDetail.vue` 中 `.post-reading-layout` 原配置为 `grid-template-columns: 220px minmax(0, 1fr)`。
- 涉及模块：Web 前台文章详情页、目录组件。

## 5. 实现内容

### 5.1 后端

- 无后端变更。

### 5.2 前端

- 将文章详情页 `.post-reading-layout` 从两列 grid 改为单列文章容器，避免目录占用正文排版空间。
- `.post-reading-layout` 改为 `width: 100%`，继续由外层 `.content` 统一约束 1200px 最大宽度，避免内部容器宽度超过父级造成左右边距变化。
- 将 `article-toc-panel` 改为跟随文章阅读容器的 sticky 悬浮面板，在大屏贴近文章卡片左侧，初始顶部与文章卡片对齐。
- 将正文阅读容器从 1080px 放宽到 1160px，减少宽屏下左右空白。
- 在 `max-width: 1680px` 下把目录转为视口左侧 sticky 浮层，默认折叠，仅保留目录标题和展开按钮；初始位置仍跟随文章卡片左侧，滚动到阈值后再吸附，避免过早固定在首屏封面区域。
- 窄屏目录通过 `margin-left` 抵消 `.content` 的居中偏移和内边距，收起/展开时都贴齐视口左边，不产生额外左侧空隙。
- 大屏展开态保留 `.content` 的 `max-width: 1200px` 约束，同时允许目录溢出显示到左侧空白区，避免被 `.post-detail` 裁剪。
- `TableOfContents` 增加 `collapsedBelow` 参数，并在组件挂载和窗口尺寸变化时同步默认展开/折叠状态。
- 为目录切换按钮补充 `aria-expanded` 和 `aria-label`。
- 目录识别规则：从 `.markdown-content` 中读取 `h1-h6` 标题，过滤空标题、隐藏标题、代码块 / 表格 / 引用块内标题，并跳过与文章主标题重复的第一项。
- 目录锚点规则：优先复用标题已有 `id`，没有 `id` 时根据标题文本生成稳定锚点；生成时会避开已有 DOM `id` 冲突。
- 目录点击滚动：改为 `requestAnimationFrame` 自定义缓动滚动，避免不同浏览器对 `behavior: smooth` 支持不一致导致跳转生硬。
- 目录视觉样式：去除当前项前面的蓝色竖条，改为小圆点、层级缩进、柔和渐变高亮和轻量玻璃背景。
- 主题变量修复：补齐 `--color-primary-rgb` 和 `--border-soft`，修复大量 `rgba(var(--color-primary-rgb), ...)` 与 `var(--border-soft)` 失效的问题。
- 状态变量收敛：新增 `--surface-glass`、`--surface-glass-muted`、`--state-primary-bg`、`--state-primary-bg-hover`、`--state-primary-bg-active`、`--state-primary-border`，目录激活态不再直接滥用主色透明度。
- 暗色模式修复：目录激活项、hover、边框和玻璃背景改用暗色语义变量，避免激活色过亮、边框不可见或过渡突兀。
- 摘要与引用块：去除大面积浅蓝底、粗蓝左边框和蓝色感叹号图标，统一为弱边框、浅表面、小圆点提示的阅读型样式。

## 8. 问题记录

| 问题 | 原因 | 处理方式 | 状态 |
| --- | --- | --- | --- |
| 目录占用正文宽度 | 目录作为 grid 左列参与主布局 | 改为悬浮定位，正文单列排版 | 已解决 |
| 窄屏目录过早固定在首屏 | 使用 fixed 定位脱离文章容器 | 改为 sticky，初始跟随文章卡片，滚动到阈值后吸附 | 已解决 |
| 窄屏目录左侧有间距 | `.content` padding 和居中偏移仍作用在目录容器上 | 使用断点下的 `margin-left` 抵消偏移，贴齐视口左侧 | 已解决 |
| 目录视觉像调试列表 | 当前项使用整条蓝色左边框，层级弱 | 改为圆点状态、层级缩进和柔和高亮 | 已解决 |
| 目录包含重复文章标题 | Markdown 第一标题可能和文章详情标题相同 | 过滤与 `.post-title` 相同的第一项 | 已解决 |
| 目录点击跳转体验不稳定 | 依赖浏览器原生 smooth 行为 | 改为自定义缓动滚动 | 已解决 |
| 暗色模式目录激活色突兀 | 组件直接使用主色透明度，且 `--color-primary-rgb` 未定义导致部分规则失效 | 补齐 RGB token，并改用语义状态变量 | 已解决 |
| 部分边框颜色不可见或失效 | 多处使用 `var(--border-soft)`，但主题未定义该变量 | 在明暗主题中补齐 `--border-soft` | 已解决 |
| 摘要和引用块提示样式过重 | 使用大面积蓝底、粗蓝边和蓝色图标，阅读时抢正文 | 改为弱提示样式，并保留明暗主题一致性 | 已解决 |
| 目录初始位置过高 | fixed 定位按 viewport 计算，未绑定文章卡片 | 改为容器内 sticky + 负左边距，初始顶部对齐文章卡片 | 已解决 |
| 宽屏目录被 `.content` 裁剪 | `.post-detail` 使用 `overflow-x: clip` 会裁掉负边距目录 | 恢复外层可见溢出，窄屏使用 fixed 浮层避免横向滚动 | 已解决 |
